# iPhone 真机验收清单(IPHONE_CHECKLIST)

正式支持范围:iOS 17+ 的 Safari。建议准备两台设备:一台小屏(iPhone SE / mini)与一台带「灵动岛」的机型。

## A. 安装与启动

- [ ] Safari 打开 `https://<域名>`,Basic Auth 登录后出现「添加到主屏幕」提示
- [ ] 主屏幕图标为品牌图标(无截图式图标),名称「储能英语」
- [ ] 独立窗口启动:无 Safari 地址栏/工具栏,状态栏为沉浸式(black-translucent)
- [ ] 启动页(闪屏)不白屏,显示品牌背景
- [ ] 冷启动(杀进程后)进入首页,无闪退

## B. 安全区与布局

- [ ] 灵动岛机型:顶部内容不被刘海/灵动岛遮挡(安全区生效)
- [ ] 底部导航不顶到 Home 指示条(`env(safe-area-inset-bottom)` 生效)
- [ ] 横屏旋转后布局正常,底部导航收窄可用,无元素溢出
- [ ] 各页面无水平滚动;动态岛机型横屏无内容被挖孔遮挡

## C. 交互与触控

- [ ] 所有按钮/导航项触控区域 ≥44×44pt(视觉 48px,适配 iOS)
- [ ] 底部导航 5 项(首页/词汇/例句/情景/文章)均可点击,激活态高亮
- [ ] 页面可双指缩放(已移除 `maximum-scale=1`),系统大字体下文字可读、不截断
- [ ] 返回行为:文章播放页返回列表、情景页返回列表均正常;iOS 边缘滑动返回不破坏应用状态

## D. 音频

- [ ] 首次点击「播放」前无自动播放;点击后音频正常(首次手势限制)
- [ ] 词汇/例句/情景/文章音频均可播放,0.85/1.0/1.15 倍速正常
- [ ] 播放中切后台再回来,播放状态正确(暂停或继续)
- [ ] 静音开关下音频行为符合预期
- [ ] 文章播放时高亮当前段落,拖动进度条后继续

## E. 语音辅助与可访问性

- [ ] VoiceOver 开启后,各按钮/图标有可读标签(aria-label / 文字)
- [ ] 系统「更大字体」开启后,首页/列表/练习页文字不重叠、可滚动查看
- [ ] 减弱动态效果后无卡顿

## F. 通知(已取消)

- [ ] 应用内无任何通知/推送设置项(每日提醒功能已按产品决策移除)
- [ ] 未向系统申请通知权限

## G. 离线与数据

- [ ] 飞行模式下:词汇、情景、文章、例句均可离线使用(语料已激活)
- [ ] 飞行模式下杀进程重开:精确续学(词汇回到上一题、情景回到上一组、文章回到上次位置)
- [ ] 设置页「关于」显示版本、存储占用、语料版本
- [ ] 导出 `.bessbackup` 到「文件」App,再从文件导入恢复

## H. 备份互通

- [ ] 本机 PWA 导出备份 → Android 端恢复成功,记忆/进度一致
- [ ] Android 端导出备份 → 本机 PWA 恢复成功

## I. 更新

- [ ] 服务器发布新版本后,打开应用出现「发现新版本」横幅
- [ ] 点击更新后应用重载为新版本,学习进度保留
- [ ] 更新期间断网不崩溃(回退到旧版本缓存)

## 已知限制(接受)

- Safari 可能因系统存储压力清理站点数据:应用保留醒目备份提示与一键导出
- iOS PWA 无自动后台同步:备份/导出均需用户主动操作
